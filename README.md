# Casa dolce casa · servizio

Questa repo pubblica fa due cose per [Casa dolce casa](https://casadolcecasa.web.app), il cui
codice sta in una repo privata:

- la **manutenzione** del gioco ogni 15 minuti (borsa, annuncio di Zero, notifiche, mondi): scarica
  il codice con una chiave di sola lettura e lo esegue;
- la **pagina del trasloco** su `tomm4so00.github.io/casadolcecasa/`, per chi apre ancora il vecchio
  indirizzo.

Qui non c'è codice del gioco.
